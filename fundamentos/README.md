## Temas

- Hardware basico: CPU, RAM, disco, red y procesos.
- Sistemas operativos: kernel, procesos, memoria, archivos y permisos.
- Redes: IP, puertos, protocolos, DNS, DHCP, HTTP, TLS y NAT.
- Seguridad basica: confidencialidad, integridad, disponibilidad, autenticacion, autorizacion y auditoria.
- Riesgo: amenaza, vulnerabilidad, impacto y probabilidad.
