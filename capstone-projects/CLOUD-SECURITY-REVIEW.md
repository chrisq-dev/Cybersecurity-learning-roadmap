# Capstone: Cloud Security Review

## Objetivo

Revisar una arquitectura cloud ficticia y proponer mejoras.

## Escenario

Una app en cloud tiene:

- Web app.
- Storage de archivos.
- Base de datos.
- Usuarios admin.
- Logs.
- Secrets.
- CI/CD.

## Tareas

1. Identificar identidades humanas y no humanas.
2. Revisar IAM.
3. Revisar storage publico.
4. Revisar logging.
5. Revisar secrets.
6. Revisar red.
7. Definir alertas.
8. Crear plan de remediacion.

- Priorizacion con contexto.
- Controles IAM concretos.
- Logging y alertas definidos.
- Riesgos de storage cubiertos.
