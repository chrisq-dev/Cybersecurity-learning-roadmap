## Objetivo

Un capstone debe mostrar que puedes unir fundamentos, practica, documentacion, riesgo y remediacion.

Cada proyecto debe tener:

- Objetivo.
- Alcance.
- Metodologia.
- Evidencia.
- Hallazgos.
- Riesgo.
- Recomendaciones.
- Limitaciones.
- Lecciones aprendidas.
