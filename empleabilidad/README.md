# Empleabilidad en Ciberseguridad

Esta carpeta conecta el estudio con conseguir trabajo. El objetivo no es solo aprender temas, sino demostrar habilidades con evidencia: notas, labs, scripts, reportes y proyectos.

## Roles Iniciales Realistas

- SOC Analyst Junior.
- Cybersecurity Analyst Junior.
- IT Support con enfoque en seguridad.
- NOC Analyst con ruta a seguridad.
- Vulnerability Management Junior.
- Cloud Security Intern / Junior.
- AppSec Intern / Junior.
- GRC Junior si te interesa riesgo y cumplimiento.

## Habilidades que Debes Demostrar

- Entender redes.
- Leer logs.
- Usar Linux y Windows.
- Explicar riesgos.
- Documentar hallazgos.
- Automatizar tareas simples.
- Investigar alertas.
- Entender OWASP Top 10.
- Trabajar con GitHub.
- Comunicar claramente.

## Evidencia para GitHub

Tu GitHub debe mostrar:

- Guia de estudio organizada.
- Laboratorios documentados.
- Scripts simples pero utiles.
- Reportes claros.
- Notas tecnicas con tus palabras.
- Proyectos terminados.
