# Inicio Aqui

Esta es la entrada recomendada para estudiar la guia. La idea es avanzar poco a poco, en orden, entendiendo primero fundamentos y despues areas mas especializadas.

No necesitas leer todo en un dia. Usa la web como biblioteca de recursos: abre una guia, estudia el concepto, revisa ejemplos, practica en entornos seguros y vuelve cuando necesites reforzar.

## Como Usar la Web

- Usa las rutas por perfil si quieres explorar un area concreta.
- Usa el buscador si ya sabes que concepto quieres revisar.
- Usa los filtros por nivel para separar contenido inicial, intermedio, avanzado y de referencia.
- Guarda una lectura solo como marcador local; no es una tarea obligatoria.
- Vuelve a fundamentos cuando una guia avanzada se sienta confusa.

## Ruta por Etapas

### 1. Base Tecnica

Objetivo: entender computadoras, sistemas operativos, permisos, redes, Linux y HTTP.

Modulos principales:

- Fundamentos.
- Redes Cisco.
- Linux.
- Windows y Active Directory.
- Programacion.
- Web OWASP.

### 2. Defensa y Analisis

Objetivo: entender logs, alertas, deteccion, respuesta e investigacion.

Modulos principales:

- Blue Team.
- SIEM y MITRE.
- Detection Engineering.
- Endpoint Security.
- Network Security.
- Playbooks.

### 3. Seguridad Aplicada

Objetivo: entender como se protegen aplicaciones, APIs, cloud, datos e identidad.

Modulos principales:

- AppSec y DevSecOps.
- API Security.
- Cloud Security.
- Identity Access.
- Database Security.
- Containers Kubernetes.

### 4. Especializacion y Portafolio

Objetivo: conectar conocimiento con proyectos, reportes y perfil profesional.

Modulos principales:

- GRC.
- Forense.
- Malware Basico.
- Red Team autorizado.
- Capstone Projects.
- Empleabilidad.

## Criterio Para Avanzar

Avanza a la siguiente guia cuando puedas:

- explicar el concepto con tus palabras;
- dar un ejemplo realista;
- identificar el riesgo de seguridad;
- mencionar controles o mitigaciones;
- reconocer errores comunes;
- practicarlo en un laboratorio o entorno autorizado cuando aplique.

## Regla Etica

Todo escaneo, prueba, explotacion o analisis debe hacerse solo en sistemas propios, laboratorios o entornos con permiso explicito.

Esta guia existe para aprender ciberseguridad de forma responsable.
