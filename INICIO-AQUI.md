# Inicio Aquí

Esta es la entrada recomendada para estudiar la guía. La idea es avanzar poco a poco, en orden, entendiendo primero fundamentos y después áreas más especializadas.

No necesitas leer todo en un día. Usa la web como biblioteca de recursos: abre una guía, estudia el concepto, revisa ejemplos, practica en entornos seguros y vuelve cuando necesites reforzar.

## Ruta por Etapas

### 1. Base Técnica

Objetivo: entender computadoras, sistemas operativos, permisos, redes, Linux y HTTP.

Módulos principales:

- Fundamentos.
- Redes Cisco.
- Linux.
- Windows y Active Directory.
- Programación.
- Web OWASP.

### 2. Defensa y Análisis

Objetivo: entender logs, alertas, detección, respuesta e investigación.

Módulos principales:

- Blue Team.
- SIEM y MITRE.
- Detection Engineering.
- Endpoint Security.
- Network Security.
- Respuesta a Incidentes (PICERL).

### 3. Seguridad Aplicada

Objetivo: entender como se protegen aplicaciones, APIs, cloud, datos e identidad.

Módulos principales:

- AppSec y DevSecOps.
- API Security.
- Cloud Security.
- Identity Access.
- Database Security.
- Containers Kubernetes.

### 4. Especialización y Portafolio

Objetivo: conectar conocimiento con la construcción de un "Home Lab" y el perfil profesional.

Módulos principales:

- GRC.
- Forense.
- Malware Básico.
- Red Team autorizado.
- Empleabilidad y Portafolio de Élite.

## Criterio Para Avanzar

Avanza a la siguiente guía cuando puedas:

- Explicar el concepto con tus palabras;
- Dar un ejemplo realista;
- Identificar el riesgo de seguridad;
- Mencionar controles o mitigaciones;
- Reconocer errores comunes;
- Practicarlo en un laboratorio o entorno autorizado cuando aplique.

## Regla Ética

Todo escaneo, prueba, explotación o análisis debe hacerse solo en sistemas propios, laboratorios o entornos con permiso explícito.

Esta guía existe para aprender ciberseguridad de forma responsable.
