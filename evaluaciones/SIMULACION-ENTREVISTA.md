# Simulacion de Entrevista

## Formato

Responde en voz alta y luego escribe una versión breve.

## Parte 1: Presentacion

1. Cuentame sobre ti y tu interés en ciberseguridad.
2. Qué estas estudiando ahora?
3. Qué proyecto de tu GitHub te representa mejor?
4. Qué haces cuándo no sabes algo?

## Parte 2: Fundamentos

1. Explicame que ocurre cuando visitas una página web.
2. Cómo diagnosticarias qué una web no carga?
3. Cómo revisarias permisos en Linux?
4. Qué logs revisarias ante intentos fallidos de login?

## Parte 3: Caso SOC

Caso:

```text
Un usuario tuvo 20 logins fallidos desde una IP externa y luego un login exitoso.
```

Una respuesta solida cubre:

- Qué datos observaste?
- Qué hipótesis haces?
- Qué buscarias después?
- Qué acción recomendarias?
- Qué detección propondrias?

## Parte 4: Caso Web

Caso:

```text
Un usuario puede cambiar /invoices/1001 por /invoices/1002 y ver facturas ajenas.
```

Una respuesta solida cubre:

- Qué vulnerabilidad es?
- Cuál es el impacto?
- Cómo se mitiga?
- Qué prueba harias en un lab?

## Parte 5: Caso Cloud

Caso:

```text
Un bucket contiene archivos sensibles y permite acceso público.
```

Una respuesta solida cubre:

- Riesgo.
- Impacto.
- Remediación.
- Como validar.
- Que alerta crearias.

## Parte 6: Preguntas Para el Entrevistador

Puedes preguntar:

- Cómo es el proceso de investigación de alertas?
- Qué fuentes de logs usan?
- Cómo documentan incidentes?
- Qué habilidades esperan qué desarrolle en 90 días?
- Cómo se mide el éxito del rol?

## Criterio

Buena respuesta:

- Clara.
- Honesta.
- Basada en evidencia.
- Incluye impacto.
- Incluye siguiente paso.
