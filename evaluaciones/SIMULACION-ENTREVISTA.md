# Simulacion de Entrevista

## Formato

Responde en voz alta y luego escribe una version breve.

## Parte 1: Presentacion

1. Cuentame sobre ti y tu interes en ciberseguridad.
2. Que estas estudiando ahora?
3. Que proyecto de tu GitHub te representa mejor?
4. Que haces cuando no sabes algo?

## Parte 2: Fundamentos

1. Explicame que ocurre cuando visitas una pagina web.
2. Como diagnosticarias que una web no carga?
3. Como revisarias permisos en Linux?
4. Que logs revisarias ante intentos fallidos de login?

## Parte 3: Caso SOC

Caso:

```text
Un usuario tuvo 20 logins fallidos desde una IP externa y luego un login exitoso.
```

Una respuesta solida cubre:

- Que evidencia tienes?
- Que hipotesis haces?
- Que buscarias despues?
- Que accion recomendarias?
- Que deteccion propondrias?

## Parte 4: Caso Web

Caso:

```text
Un usuario puede cambiar /invoices/1001 por /invoices/1002 y ver facturas ajenas.
```

Una respuesta solida cubre:

- Que vulnerabilidad es?
- Cual es el impacto?
- Como se mitiga?
- Que prueba harias en un lab?

## Parte 5: Caso Cloud

Caso:

```text
Un bucket contiene archivos sensibles y permite acceso publico.
```

Una respuesta solida cubre:

- Riesgo.
- Impacto.
- Remediacion.
- Como validar.
- Que alerta crearias.

## Parte 6: Preguntas Para el Entrevistador

Puedes preguntar:

- Como es el proceso de investigacion de alertas?
- Que fuentes de logs usan?
- Como documentan incidentes?
- Que habilidades esperan que desarrolle en 90 dias?
- Como se mide el exito del rol?

## Criterio

Buena respuesta:

- Clara.
- Honesta.
- Basada en evidencia.
- Incluye impacto.
- Incluye siguiente paso.
