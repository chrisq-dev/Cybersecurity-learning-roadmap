# Checklist de Progreso

Marca cada punto cuando puedas explicarlo y practicarlo, no solo cuando lo hayas leido.

## Fundamentos

- [ ] Explico confidencialidad, integridad y disponibilidad.
- [ ] Diferencio amenaza, vulnerabilidad, riesgo e impacto.
- [ ] Entiendo procesos, memoria, archivos y permisos.
- [ ] Conozco puertos comunes y servicios basicos.
- [ ] Explico OSI y TCP/IP con ejemplos.

## Redes y Cisco

- [ ] Calculo subredes IPv4.
- [ ] Entiendo CIDR.
- [ ] Explico switching y routing.
- [ ] Entiendo VLANs y trunking.
- [ ] Entiendo NAT y ACLs.
- [ ] Analizo trafico basico en Wireshark.
- [ ] Diagnostico problemas basicos con `ping`, `traceroute`, `dig` y `curl`.

## Linux

- [ ] Uso comandos basicos con comodidad.
- [ ] Manejo permisos con `chmod` y `chown`.
- [ ] Entiendo usuarios y grupos.
- [ ] Reviso procesos y servicios.
- [ ] Reviso logs relevantes.
- [ ] Escribo scripts simples en Bash.
- [ ] Conozco hardening basico de SSH.

## Windows y Active Directory

- [ ] Entiendo usuarios, grupos y permisos.
- [ ] Uso Event Viewer.
- [ ] Uso PowerShell basico.
- [ ] Explico que es Active Directory.
- [ ] Entiendo Kerberos a nivel conceptual.
- [ ] Entiendo GPOs a nivel conceptual.

## Programacion

- [ ] Escribo scripts basicos en Python.
- [ ] Leo y escribo archivos.
- [ ] Trabajo con JSON y CSV.
- [ ] Uso expresiones regulares.
- [ ] Consumo una API.
- [ ] Uso Git para documentar cambios.

## Seguridad Web y OWASP

- [ ] Entiendo HTTP requests y responses.
- [ ] Entiendo cookies y sesiones.
- [ ] Diferencio autenticacion y autorizacion.
- [ ] Explico OWASP Top 10.
- [ ] Practique SQL Injection en labs.
- [ ] Practique XSS en labs.
- [ ] Practique Broken Access Control en labs.
- [ ] Documento impacto y remediacion.

## Blue Team

- [ ] Analizo logs de autenticacion.
- [ ] Entiendo que hace un SIEM.
- [ ] Uso MITRE ATT&CK como referencia.
- [ ] Creo una regla Sigma basica.
- [ ] Creo una regla YARA basica.
- [ ] Documento una investigacion de alerta.

## Red Team Controlado

- [ ] Entiendo reconocimiento y enumeracion.
- [ ] Uso escaneo solo en entornos autorizados.
- [ ] Documento metodologia.
- [ ] Incluyo remediacion en reportes.
- [ ] Respeto reglas de plataformas y labs.

## Cloud Security

- [ ] Explico responsabilidad compartida.
- [ ] Entiendo IAM.
- [ ] Entiendo riesgos de storage publico.
- [ ] Entiendo logging cloud.
- [ ] Documento errores comunes de configuracion.

## Portafolio

- [ ] Tengo notas tecnicas claras.
- [ ] Tengo laboratorios documentados.
- [ ] Tengo al menos un script util.
- [ ] Tengo al menos un writeup permitido.
- [ ] Tengo un README limpio.
- [ ] No hay secretos ni datos sensibles en el repo.
