## Fase 1: Fundamentos

- Como funciona una computadora.
- Sistemas operativos: procesos, memoria, archivos, usuarios y permisos.
- Redes: OSI, TCP/IP, IP, puertos, DNS, DHCP, HTTP, TLS y routing basico.
- Terminal: comandos esenciales de Linux y Windows.
- Git y GitHub para documentar el aprendizaje.

## Fase 2: Redes y Cisco

- Modelo OSI y TCP/IP.
- IPv4, subnetting, CIDR y gateways.
- Switching, VLANs, trunking y STP.
- Routing estatico y dinamico.
- NAT, ACLs, DHCP, DNS y troubleshooting.
- Captura y analisis de trafico con Wireshark.

## Fase 3: Linux y Windows

- Linux: permisos, servicios, logs, cron, systemd, SSH y hardening.
- Bash scripting para automatizacion.
- Windows: usuarios, grupos, servicios, eventos y PowerShell.
- Active Directory: dominios, Kerberos, LDAP, GPOs y conceptos de identidad.

## Fase 4: Programacion para Seguridad

- Python para automatizar tareas.
- Bash y PowerShell.
- Expresiones regulares.
- Parsing de logs.
- Manejo de archivos, JSON, CSV y APIs.
- Git como control de versiones.

## Fase 5: Seguridad Web y OWASP

- HTTP, cookies, sesiones y autenticacion.
- APIs REST.
- OWASP Top 10.
- SQL Injection.
- XSS.
- CSRF.
- SSRF.
- Broken Access Control.
- File upload vulnerabilities.
- Seguridad de headers y configuraciones.

## Fase 6: Blue Team

- Logs de Linux, Windows, web servers y firewalls.
- SIEM: busqueda, correlacion y alertas.
- Respuesta a incidentes.
- Threat hunting.
- Sigma para detecciones.
- YARA para analisis de archivos.
- MITRE ATT&CK.

## Fase 7: Red Team Controlado

- Reconocimiento.
- Enumeracion.
- Escaneo en laboratorios.
- Explotacion controlada.
- Privilege escalation en labs.
- Reporte tecnico y remediacion.

## Fase 8: Cloud Security

- Fundamentos de AWS, Azure o GCP.
- IAM y permisos.
- Redes cloud.
- Buckets/storage expuesto.
- Logging y monitoreo.
- Errores comunes de configuracion.

## Fase 9: Especializacion

Elegir una o dos rutas iniciales:

- SOC Analyst / Blue Team.
- Pentesting web.
- Cloud security.
- AppSec.
- DFIR.
- Active Directory security.
- Detection engineering.

## Fase 10: Portafolio

- Documentar laboratorios.
- Publicar notas tecnicas limpias.
- Crear scripts pequenos pero utiles.
- Escribir reportes con impacto, evidencia y remediacion.
- Mantener el repo ordenado y etico.
