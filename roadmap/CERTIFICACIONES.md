# Certificaciones

Las certificaciones no reemplazan practica, pero pueden ayudar a ordenar estudio y abrir puertas.

## Base

### CompTIA Network+

Util si necesitas reforzar redes antes de seguridad.

### Cisco CCNA

Muy buena si quieres una base fuerte de redes. Ayuda mucho para SOC, NOC, cloud y seguridad en general.

### CompTIA Security+

Buena para fundamentos generales de ciberseguridad y puestos junior.

## Blue Team

### Blue Team Level 1

Enfocada en habilidades defensivas practicas.

### Microsoft SC-900

Intro a seguridad, cumplimiento e identidad en ecosistema Microsoft.

### Microsoft SC-200

Mas orientada a analista de seguridad con herramientas Microsoft.

## Web / Pentesting

### eJPT

Entrada practica a pentesting.

### PNPT

Mas completa y orientada a metodologia y reporte.

### PortSwigger Web Security Academy

No es certificacion tradicional en todos los casos, pero sus labs son excelentes para seguridad web.

## Cloud

### AWS Cloud Practitioner

Entrada general a AWS.

### AWS Security Specialty

Mas avanzada, mejor despues de tener base cloud.

### Azure Fundamentals AZ-900

Base de Azure.

### Microsoft SC-900

Base de seguridad e identidad en Microsoft.

## Recomendacion Inicial

Si empiezas desde cero:

1. Redes: Network+ o CCNA.
2. Seguridad general: Security+.
3. Blue Team: BTL1 o ruta equivalente practica.
4. Web: PortSwigger labs.
5. Cloud: AWS Cloud Practitioner o AZ-900.

## Regla

No estudies certificaciones solo para coleccionarlas. Cada certificacion puede dejar como evidencia:

- Notas.
- Labs.
- Checklist.
- Proyecto o reporte.
