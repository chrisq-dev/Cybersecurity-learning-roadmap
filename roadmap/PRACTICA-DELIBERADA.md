# Practica Deliberada

Leer mucho no te vuelve bueno si no practicas. Esta guia define como practicar para mejorar de verdad.

## Ciclo de Practica

1. Elegir una habilidad.
2. Hacer un ejercicio pequeño.
3. Medir resultado.
4. Corregir errores.
5. Repetir con una variacion.
6. Documentar lo aprendido.

## Ejemplos por Area

### Redes

Habilidad: entender DNS.

Ejercicios:

- Consultar registros A, MX y TXT.
- Comparar respuestas de distintos dominios.
- Explicar cache DNS.
- Capturar consulta DNS con Wireshark.

### Linux

Habilidad: permisos.

Ejercicios:

- Crear archivos con permisos distintos.
- Predecir quien puede leer, escribir o ejecutar.
- Probarlo con usuarios diferentes.
- Corregir permisos inseguros.

### Web

Habilidad: entender autenticacion.

Ejercicios:

- Analizar cookies.
- Comparar 401 y 403.
- Explicar flujo de login.
- Resolver un lab de acceso roto.

### Blue Team

Habilidad: investigar login fallido.

Ejercicios:

- Leer logs.
- Identificar usuario e IP.
- Contar frecuencia.
- Separar error normal de sospecha.
- Escribir conclusion.

### Python

Habilidad: parsing de logs.

Ejercicios:

- Leer archivo.
- Buscar palabra clave.
- Contar eventos.
- Agrupar por usuario.
- Exportar resumen.

## Como Saber si Mejoraste

Mejoraste si:

- Tardas menos.
- Cometes menos errores.
- Explicas mejor.
- Puedes variar el ejercicio.
- Puedes detectar cuando algo no cuadra.

## Regla de Repeticion

Para cada tema importante haz:

- 1 repeticion guiada.
- 1 repeticion sin guia.
- 1 repeticion con cambio.
- 1 explicacion escrita.
