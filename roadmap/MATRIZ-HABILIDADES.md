# Matriz de Habilidades

Esta matriz separa lo que necesitas para empezar, conseguir trabajo junior y crecer hacia un perfil avanzado.

## Nivel 1: Base

Objetivo: entender los sistemas y no depender solo de herramientas.

Debes dominar:

- Modelo OSI y TCP/IP.
- IP, puertos, DNS, DHCP, HTTP y TLS.
- Linux basico.
- Windows basico.
- Git y GitHub.
- CIA triad.
- Riesgo, amenaza, vulnerabilidad e impacto.
- Escritura de notas claras.

Evidencia:

- Glosario propio.
- Primeros labs completos.
- Checklist de fundamentos marcado.

## Nivel 2: Junior Empleable

Objetivo: poder trabajar como aprendiz, SOC junior, soporte con seguridad o analista junior.

Debes dominar:

- Analisis basico de logs.
- SIEM conceptual.
- MITRE ATT&CK basico.
- OWASP Top 10 basico.
- Python para scripts simples.
- PowerShell basico.
- Reportes con evidencia e impacto.
- Linux y Windows operativos.

Evidencia:

- 3 laboratorios documentados.
- 2 scripts simples.
- 2 reportes.
- 1 proyecto de portafolio terminado.
- CV y LinkedIn alineados con tus proyectos.

## Nivel 3: Intermedio

Objetivo: resolver problemas con menos guia y explicar tradeoffs.

Debes dominar:

- Investigacion de alertas.
- Detecciones Sigma.
- YARA basico.
- Seguridad web con labs.
- Active Directory conceptual y practico en lab.
- Cloud IAM y logging.
- Hardening Linux.
- Automatizacion de reportes.

Evidencia:

- 5 a 8 labs documentados.
- 3 scripts utiles.
- 3 writeups permitidos.
- 1 investigacion de alerta simulada.
- 1 guia de hardening.

## Nivel 4: Avanzado

Objetivo: diseñar, investigar y mejorar controles.

Debes dominar:

- Threat hunting.
- Detection engineering.
- Respuesta a incidentes.
- Seguridad cloud mas profunda.
- Seguridad de Active Directory.
- AppSec y threat modeling.
- DevSecOps.
- Forense basico.
- Comunicacion con negocio.

Evidencia:

- Proyectos completos con documentacion.
- Reglas de deteccion explicadas.
- Analisis con MITRE ATT&CK.
- Reportes tecnicos y ejecutivos.
- Contribuciones o mejoras continuas al repo.

## Nivel 5: Experto en Progreso

Objetivo: especializarte y crear criterio propio.

Especializaciones posibles:

- SOC / Detection Engineering.
- Cloud Security.
- AppSec.
- Pentesting Web.
- Active Directory Security.
- DFIR.
- GRC y riesgo.
- Malware Analysis.

Evidencia:

- Investigaciones profundas.
- Herramientas propias.
- Labs avanzados.
- Documentacion de arquitectura.
- Capacidad de ensenar a otros.
- Decisiones tecnicas justificadas.

## Regla Importante

No intentes estudiar todo al mismo nivel al mismo tiempo. Primero construye base, luego consigue experiencia, despues especializate.
