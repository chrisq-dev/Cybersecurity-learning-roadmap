# Writeups

Reportes y soluciones de retos que se puedan compartir publicamente.

Antes de publicar un writeup, revisar las reglas de la plataforma y evitar spoilers activos, flags, credenciales o datos privados.

## Plantilla de Writeup

```md
# Nombre del Reto

## Plataforma

Nombre de la plataforma o laboratorio.

## Objetivo

Descripcion breve del reto.

## Metodologia

Proceso general usado para resolverlo.

## Hallazgos

Observaciones tecnicas importantes.

## Impacto

Que riesgo representa el hallazgo.

## Remediacion

Como se podria prevenir o corregir.

## Lecciones Aprendidas

Que aprendi del reto.
```
