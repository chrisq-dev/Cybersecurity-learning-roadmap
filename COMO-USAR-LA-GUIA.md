# Como Usar Esta Guia

Esta guia esta pensada como un mapa de aprendizaje de ciberseguridad en espanol. No necesitas leer todo en orden perfecto. La idea es entender el panorama, elegir una ruta y volver a los fundamentos cuando algo no quede claro.

## Idea Principal

La ciberseguridad no se aprende memorizando listas de herramientas. Se aprende conectando conceptos:

```text
fundamentos -> sistemas -> redes -> aplicaciones -> datos -> deteccion -> respuesta -> riesgo
```

Cada tema intenta responder cuatro preguntas:

- que es;
- por que importa;
- donde aparece en sistemas reales;
- como se protege, detecta o analiza.

Empieza por:

1. [INICIO-AQUI.md](INICIO-AQUI.md)

No intentes dominar todo en una pasada. La primera lectura sirve para ubicar conceptos.

## Como Leer una Leccion

Una buena lectura tiene este flujo:

```text
leer -> conectar -> probar mentalmente -> revisar ejemplos -> volver despues
```

Mientras lees, busca:

- definiciones simples;
- ejemplos;
- riesgos;
- controles;
- evidencia;
- errores comunes;
- criterios de comprension.

## Rutas por Perfil

La home muestra rutas por perfil. Usalas como mapas:

- Fundamentos: base tecnica general.
- Blue Team: logs, SIEM, MITRE, deteccion y respuesta.
- AppSec: web, APIs, OWASP, autenticacion y autorizacion.
- Cloud: IAM, storage, logging, Kubernetes y responsabilidad compartida.
- GRC: riesgo, controles, evidencia, privacidad y continuidad.
- Empleabilidad: portafolio, entrevistas, CV y rutas por rol.

Puedes cambiar de ruta, pero conviene no saltar fundamentos si un concepto se siente borroso.

## Niveles

La web clasifica contenido en niveles:

- Inicial: conceptos base y primeros mapas.
- Intermedio: temas que conectan con trabajo real.
- Avanzado: investigaciones, arquitectura, capstones o temas con mas contexto.
- Referencia: cheatsheets, plantillas y material de consulta rapida.

El nivel no significa importancia. Un tema inicial puede ser mas importante que uno avanzado.

## Como Usar la Busqueda

La busqueda revisa titulos, categorias y contenido. Sirve para encontrar conceptos especificos como:

- MFA;
- Kerberos;
- SQL Injection;
- logs;
- IAM;
- backups;
- phishing;
- MITRE.

Si un resultado aparece por contenido, la tarjeta puede mostrar un extracto.

## Como Usar el Progreso

El progreso se guarda localmente en tu navegador. Sirve como orientacion personal, no como calificacion.

Puedes usarlo para recordar que paginas ya revisaste, pero no confundas marcar una pagina con dominar el tema.

## Que Significa Entender un Tema

Entender un tema significa poder explicarlo con tus palabras y conectarlo con riesgo real.

Ejemplo:

```text
No basta saber que MFA existe.
Tambien importa saber que riesgo reduce, donde aplicarlo, que limitaciones tiene y como verificarlo.
```

## Como Volver a Esta Guia

Usa la guia como referencia viva:

- cuando encuentres una palabra nueva;
- cuando quieras repasar antes de una entrevista;
- cuando quieras entender un incidente;
- cuando quieras planear un proyecto;
- cuando quieras ordenar tus notas.

## Regla Etica

Todo lo relacionado con pruebas, escaneo, explotacion o analisis debe hacerse solo en sistemas propios, laboratorios o entornos con autorizacion explicita.

La meta de esta guia es aprender, defender, investigar con criterio y construir una base profesional.
