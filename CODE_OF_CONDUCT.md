# Código de conducta

Este proyecto busca un espacio de aprendizaje respetuoso, técnico y accesible.

## Expectativas

- Trata a las demás personas con respeto.
- Critica ideas y código, no a las personas.
- Explica el contexto de tus afirmaciones técnicas.
- Respeta la privacidad y no publiques datos personales.
- No promuevas ataques, abuso, acoso ni acceso no autorizado.
- Acepta correcciones y corrige errores de buena fe.

## Aplicación

Los maintainers pueden editar, cerrar o rechazar contribuciones que incumplan estas normas. Para reportar una conducta inapropiada, usa el reporte privado de GitHub o contacta a [@chrisq-dev](https://github.com/chrisq-dev).

Este código se inspira en el [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
