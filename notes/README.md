# Notas

Apuntes tecnicos, resumenes, diagramas y explicaciones creadas durante el estudio.

## Formato Sugerido

- Concepto.
- Para que sirve.
- Como funciona.
- Comandos o ejemplos.
- Riesgos de seguridad.
- Buenas practicas.
- Referencias.

## Donde Escribir Cada Cosa

- Respuestas a preguntas: `evaluaciones/RESPUESTAS.md`.
- Notas largas de temas: `notes/`.
- Dudas e ideas futuras: `notes/PENDIENTES.md`.
- Estado de avance: `roadmap/DONDE-VOY.md`.
- Tareas activas: `roadmap/TABLERO.md`.

Usa [PLANTILLA-RESPUESTA.md](PLANTILLA-RESPUESTA.md) cuando quieras contestar una pregunta con formato profesional.
