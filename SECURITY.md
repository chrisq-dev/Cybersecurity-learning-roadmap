# Politica de Seguridad

Este repositorio es educativo y no debe contener secretos, credenciales, informacion privada de objetivos reales ni resultados de pruebas no autorizadas.

## Reglas para Contenido Publico

- No subir API keys, contrasenas, tokens, llaves privadas o cookies de sesion.
- No publicar resultados de sistemas reales sin permiso explicito.
- No incluir datos personales, informacion de clientes o detalles de infraestructura privada.
- No publicar spoilers de plataformas que lo prohiban.
- No subir capturas que revelen informacion sensible.

## Si se Sube Informacion Sensible

Eliminarla del repositorio, rotar el secreto afectado y revisar el historial si fue publicado.
