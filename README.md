# Ciberseguridad

Repositorio personal para estudiar, practicar y documentar ciberseguridad de forma ordenada.

La idea de este repo es construir una base completa: fundamentos, redes, Linux, Windows, Cisco, seguridad web, OWASP, blue team, cloud, Active Directory, scripting, laboratorios, writeups y recursos.

Aunque este repo nace como mi ruta personal de aprendizaje, esta abierto para cualquier persona que quiera estudiar ciberseguridad de forma responsable, ordenada y etica.

## Proposito Publico

Este repositorio puede servir para:

- Estudiantes que no saben por donde empezar.
- Personas de IT, soporte o redes que quieren moverse a ciberseguridad.
- Principiantes que necesitan una ruta completa y practica.
- Personas que quieren construir portafolio con notas, labs, scripts y reportes.

El enfoque es aprender haciendo: leer, practicar, responder preguntas, documentar evidencia y mejorar con el tiempo.

## Objetivo

Aprender ciberseguridad con profundidad suficiente para entender cómo funcionan los sistemas, cómo se atacan, cómo se defienden y cómo se documentan los hallazgos de forma profesional.

## Areas de Estudio

- Fundamentos de computacion, sistemas operativos y redes.
- Redes tipo Cisco: switching, routing, VLANs, ACLs, NAT, DHCP, DNS y troubleshooting.
- Linux: terminal, permisos, procesos, servicios, logs, hardening y scripting.
- Windows: administracion, PowerShell, eventos, servicios, usuarios, permisos y Active Directory.
- Seguridad web: HTTP, autenticacion, sesiones, APIs y OWASP Top 10.
- Blue Team: logs, SIEM, deteccion, respuesta a incidentes, Sigma, YARA y threat hunting.
- Red Team basico: reconocimiento, enumeracion, explotacion en labs y post-explotacion controlada.
- Security teams y hats: Red Team, Blue Team, Purple Team, White Team, White Hat, Black Hat, Gray Hat y roles modernos.
- Cloud security: IAM, redes cloud, storage, logging, monitoreo y errores comunes.
- Criptografia aplicada: hashing, cifrado, certificados, TLS y manejo de secretos.
- Programacion y automatizacion: Python, Bash, PowerShell, Git y expresiones regulares.
- Reportes: metodologia, evidencia, impacto, remediacion y comunicacion tecnica.
- Empleabilidad: portafolio, CV, entrevistas, aplicaciones y evidencia para roles junior.

## Reglas Eticas

Todo el contenido de este repositorio es educativo. Cualquier prueba, escaneo, explotacion o analisis debe realizarse unicamente en sistemas propios, autorizados o disenados como laboratorios.

No se deben subir credenciales, tokens, datos personales, informacion privada, resultados de sistemas reales sin permiso o spoilers prohibidos por plataformas de practica.

Si usas este repo para aprender, manten el mismo principio: practica solo en entornos propios, autorizados o creados para laboratorio.
