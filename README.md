# Cybersecurity Learning Roadmap

Tu hoja de ruta para aprender ciberseguridad en español sin perderte.

## La filosofía de esta guía

Esto no es un mapa cerrado que promete enseñarte todo. La ciberseguridad es infinita. Esto es un mapa vivo y estructurado para que no te pierdas, vayas a tu propio ritmo y lo uses como brújula de consulta constante.

## Quién soy y por qué hice este proyecto

Hola, soy Christian Quiñones, desarrollador backend y estudiante enfocado en ciberseguridad. Empecé este proyecto porque, al estudiar, muchas veces me sentía perdido entre fundamentos, herramientas, certificaciones, laboratorios y rutas que asumían conocimientos previos.

Diseñé esta web para recopilar, explicar y ordenar recursos de ciberseguridad en español. Mi objetivo es construir el mapa que me habría gustado encontrar al comenzar: una guía que ayude a entender por qué importa cada tema, cómo se conecta con los demás y qué conviene estudiar después.

También es mi forma de aprender en público. El contenido seguirá creciendo y corrigiéndose conforme estudio, practico en entornos autorizados y recibo contribuciones de otras personas. No pretende reemplazar documentación oficial, formación profesional ni experiencia práctica; busca ofrecer una base clara para llegar mejor preparado a ellas.

## Qué encontrarás aquí

El contenido está organizado como un mapa vivo de conocimientos técnicos, defensivos y profesionales:

- **Fundamentos técnicos:** computación, sistemas operativos, redes, Linux, Windows y permisos.
- **Seguridad web, AppSec y Móvil:** HTTP, OWASP Top 10, APIs, DevSecOps, Mobile Pentesting e Ingeniería Inversa.
- **Blue Team, OSINT y respuesta:** logs, SIEM, MITRE ATT&CK, Threat Intelligence (CTI), OSINT y respuesta a incidentes.
- **Cloud, IoT y arquitectura:** IAM, Kubernetes, Zero Trust, SCADA/OT, IoT y Hardware Hacking.
- **Seguridad en IA:** ataques semánticos, OWASP Top 10 para LLMs, Prompt Injection y defensa con IA.
- **Criptografía, malware y forense:** cifrado, hashing, TLS, ransomware, botnets, memoria, disco y cadena de custodia.
- **GRC, privacidad y continuidad:** riesgo, controles, evidencia, backups, continuidad y privacidad.
- **Empleabilidad:** rutas por rol, CV, LinkedIn, entrevistas, portafolio y criterios para aplicar.
- **Recursos y cultura tech:** cómo usar la guía, roadmap inicial, plataformas de práctica, glosario hacker, certificaciones y referencias geek.

Cada guía vive como un archivo Markdown dentro del repositorio. La web descubre esos archivos, los ordena por área y los convierte en páginas navegables.

## Ética

Todo el contenido es educativo.

Cualquier prueba, escaneo, explotación o análisis debe realizarse solo en:

- Sistemas propios;
- Laboratorios locales;
- Plataformas de práctica autorizadas;
- Entornos donde exista permiso explícito.

No uses este material contra terceros, redes públicas, empresas, usuarios o sistemas sin autorización.
